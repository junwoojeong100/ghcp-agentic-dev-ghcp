**리허설 승인 범위에 맞춰 UI 오류 상태와 회귀 테스트를 수정했습니다.** 이는 자동 리허설 기록에 따른 작업이며, 사람의 승인을 뜻하지 않습니다.

`public/app.mjs`는 요청 실패·부분 실패·주문 수 불일치·목록 조회 실패를 `ok`로 표시하지 않고, 오류 코드와 기존 확인 안내를 피드백에 표시합니다. 이전 오류가 있어도 재시도가 성공하고 주문 수가 맞으면 정상 상태로 회복합니다. `public/index.html`에는 상태 안내를 보완했고, `tests/app.test.mjs`에는 실패·부분 성공·목록 오류·재시도 회복 테스트를 추가했습니다. 멱등성 처리는 `src/app.mjs`에 이미 있어 수정하지 않았습니다.

테스트와 브라우저 확인은 요청대로 실행하지 않았습니다. 이전 브라우저 점검에서 지적된 오류 코드 누락과 실패 응답의 잘못된 `ok` 표시는 수정 대상으로 반영했으며, 결과 검증은 컨트롤러가 수행해야 합니다.
