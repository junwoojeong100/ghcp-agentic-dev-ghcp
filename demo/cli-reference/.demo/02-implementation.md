**구현 반영:** 동시·순차 재전송을 처리하는 서버 멱등성 로직과 결과 UI는 현재 허용 파일에 구현되어 있습니다. 요청 실패·부분 실패·주문 수 불일치·목록 조회 실패는 정상(`ok`) 상태가 되지 않고, 응답 오류 코드를 피드백에 표시하며 성공적인 재시도 뒤에는 정상 상태로 회복합니다. 이전 저장소 테스트 기록의 구문 오류를 고치고, 부분 실패 배너 상태를 확인하는 회귀 assertion도 추가했습니다.

**검증 상태:** 요청에 따라 테스트와 브라우저 확인은 실행하지 않았습니다. 기존 기록에는 테스트 로딩 구문 오류와 브라우저 오류 표시 실패가 남아 있으므로, 현재 수정 결과는 컨트롤러의 재검증이 필요합니다. 이번 패치에서 수정한 파일은 `tests/app.test.mjs`이며, 리허설 승인 기록은 사람의 승인으로 간주하지 않습니다.
